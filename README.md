# 高精度行人车辆检测与追踪系统 (Pedestrian & Vehicle Tracking)

## 📌 项目简介
本项目是一个基于 **YOLOv8 深度学习模型**与 **Tkinter 图形用户界面**开发的桌面端实时目标检测与追踪系统。旨在为智慧交通、安防监控等场景提供轻量级的视觉分析方案。系统不仅支持高精度的目标检测，还内置了多目标追踪算法，能够为画面中的行人和车辆分配唯一追踪 ID，并支持用户进行深度交互分析。

## 🚀 核心功能
* **多源数据输入**：支持单张图片、整个文件夹批量读取、本地视频文件以及本地摄像头实时画面接入。
* **实时多目标追踪 (MOT)**：集成 YOLO 追踪算法，不仅画框检测，还能为每个移动目标分配独立的追踪 ID。
* **动态参数调节**：界面内置参数面板，支持**实时动态调整置信度阈值（Confidence）**和**交并比阈值（IoU）**，无需重启程序即可适应不同场景的检测需求。
* **深度交互式目标选择**：底部的 Treeview 表格实时展示所有目标的详细信息。用户可通过下拉框或点击表格行，**精准选中特定目标，画面中对应的目标框会高亮变红**，并展示其精确的边界坐标（xmin, ymin, xmax, ymax）与置信度。
* **数据统计与导出**：实时统计画面中的总目标数、行人数目和车辆数目；支持一键保存带有检测框和追踪信息的图片至本地。

## 🛠️ 技术栈
* **界面开发**：`Tkinter` (内置 `ttk.Treeview` 表格组件与下拉框交互)
* **深度学习框架**：`Ultralytics` (YOLOv8 目标检测与追踪模型)
* **图像处理**：`OpenCV` (视频流读取、画框渲染、色彩空间转换), `Pillow` (GUI 图像渲染)
* **数据处理**：`NumPy`, `collections.Counter` (实现高效的目标分类统计)

## 💡 工程落地亮点（开发难点与解决）
1. **中文路径兼容优化**：针对 Windows 环境下读取含中文字符路径图片失败的问题，采用 `np.fromfile` 结合 `cv2.imdecode` 的字节流解码方式，保证了系统的健壮性。
2. **界面与算法的高效解耦**：利用多线程/定时器（`self.after`）机制驱动视频帧循环（`video_loop`），保证在模型推理的同时，GUI 界面依然能保持流畅响应，避免卡顿。
3. **交互体验深度优化**：设计了「数据双向绑定」逻辑。表格列表、下拉框与图像画面的高亮框完全联动。用户点击表格中的某一行，画面中对应的目标框立即变红提示，极大提升了视觉分析的效率。
